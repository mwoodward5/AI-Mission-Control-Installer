# Lovable Site Build Prompt

Use this when Mission Control routes a local business site, landing page, SEO page, or Lovable build prompt.

```text
Build or improve this site/project using the existing project structure.

Business/task:
{{TASK}}

Rules:
- Do not mention Lovable on the public-facing site unless I explicitly ask.
- Make the design high-end, modern, cinematic, and mobile-first.
- Use strong hero section, clear CTAs, trust signals, service sections, local SEO structure, FAQs, and schema where appropriate.
- Avoid generic template sameness.
- Keep performance fast.
- Preserve working integrations.
- Do not break existing routing.
- Do not remove pages unless clearly obsolete and approved.

Output:
1. What you changed
2. Pages/components updated
3. SEO/schema improvements
4. Visual improvements
5. Build/test result
6. Next best improvement
```
