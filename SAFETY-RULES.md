# Safety Rules

- never expose API keys
- never save cookies
- never save passwords
- never force push
- never delete repos
- never delete models automatically
- never overwrite `.env`
- never run destructive PowerShell silently
- always show dangerous commands before running
- always backup before editing many files
- prefer dry-run checks before direct actions
- never bypass logins or capture credentials

If unsure, use local-first manual execution and explicit user confirmation.
